[Replay](https://replay.pokemonshowdown.com/gen9badnboosted-2703189072)

The public log confirms several poor sequences. It does not contain the advisor's
search states, recommendations, predicted switch probabilities, or either team's
full private sets. The analysis below distinguishes observed play from reproduced
engine behavior. It cannot establish that every played move followed a recommendation.

## Reproduced native mechanics bug and fix

The installed upstream `poke-engine` 0.0.48 ignored offensive boosts for ordinary
damage into Unaware, but incorrectly retained them for critical damage. It also
incorrectly retained defensive drops on critical hits when the attacker had
Unaware. Showdown's [Unaware implementation](https://github.com/smogon/pokemon-showdown/blob/master/data/abilities.ts)
suppresses these boosts without a critical-hit exemption.

For an explicit illustrative fixture (Timid 252 HP / 4 SpA / 252 Spe Flutter Mane
against Careful 252 HP / 252 SpD Dondozo), maximum Shadow Ball damage was:

| Calm Minds | Normal hit, before patch | Critical hit, before patch | Critical hit, after patch |
| --- | --- | --- | --- |
| 0 | 81 | 121 | 121 |
| 1 | 81 | 180 | 121 |
| 2 | 81 | 238 | 121 |

These are explicit test assumptions, not recovered private EVs. In this fixture,
unboosted maximum Moonblast damage is 96 versus Shadow Ball's 81, approximately
19% higher. The calculation already recognizes the stronger immediate attack;
it is not a base-power lookup error.

The native patch is built by [the pinned installer](../scripts/install_poke_engine.py).
It applies Unaware's existing normal-hit stat suppression to critical-hit stats
too. The installed version is `0.0.48+foulplay.1`. Seven new mechanics regressions
failed on the original engine and pass with this patch. The regression suite also
checks that Mold Breaker bypass and Stored Power scaling continue to work.

## Remaining strategy limitations

The native evaluator awards flat bonuses for boosts: a first Calm Mind earns 45
heuristic points from Special Attack/Special Defense, regardless of whether the
current opponent can exploit or ignore those changes. It does not evaluate the
specific matchup value of each surviving team member. Longer searches can reveal
some consequences, but they retain this imperfect evaluation at unfinished leaves.

The engine searches both players' actions; it does not learn from this game that a
particular opponent prefers staying in, attacking, recovering, or phazing. Existing
opponent memory retains revealed sets, not an action policy. The installed patch
corrects a concrete mechanics error; it does not solve these strategy limitations.

A further strategy change needs replayable advisor decision traces to compare
original and revised recommendations under the same private states and sampled
sets. Fresh decision traces are saved by the advisor in its local log directory.
